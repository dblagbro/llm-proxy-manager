# (a) RESOLVED 2026-10-03 — this was BUG-095, a real billing bug, not a test bug.
#     Three of the four now pass. `call_with_tool_prompt` was discarding the
#     upstream `resp.usage`, and the six emulated-response builders filled in
#     hardcoded zeros, so usage and every cost derived from it read $0. The path
#     is common: the proxy injects its own MCP tools, which makes `has_tools`
#     true even when the caller sent none, so emulation engages for any provider
#     without native tool support. Fixed in v5.22.41; see bug-log BUG-095.
#
# (a2) emulated SSE stream omits the opening `message_start` frame (1)
#     Diagnosed 2026-10-03 while fixing BUG-095, and it is a DIFFERENT bug —
#     protocol conformance, not accounting. `anthropic_text_sse` yields
#     content_block_start / content_block_delta / content_block_stop /
#     message_delta / message_stop, with no `message_start`. The Anthropic
#     streaming contract requires it first, and it is the frame that carries
#     `input_tokens`, so a strict SDK client on the emulation path may error and
#     input tokens have nowhere to be reported.
#
#     Not bundled into the v5.22.41 commit on purpose: it needs `model` threaded
